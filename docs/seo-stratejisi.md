## 2. URL Mimarisi

### 2.1 Mevcut Rotalar (Korunacak ve İyileştirilecek)

```
/m/[slug]              → QR menü sayfası (canonical: /isletme/[slug])
/qr/[businessId]       → QR generator
```

### 2.2 Yeni SEO Rotaları (Öncelik Sırasıyla)

#### Tier 1: Şehir + Kategori (1.215 sayfa)
```
/[sehir]/[kategori]

Örnekler:
/istanbul/kahvalti
/istanbul/kebap
/ankara/pizza
/izmir/balik
/gaziantep/doner
```

**Amaç:** Şehir bazlı kategori sorguları
**Hedef keyword türü:** `[şehir] [kategori] yerleri`
**Sayfa içi SEO:** H1, listing grid, fiyat karşılaştırma modülü, FAQ, breadcrumb

#### Tier 2: Şehir + İlçe + Kategori (6.075 sayfa)
```
/[sehir]/[ilce]/[kategori]

Örnekler:
/istanbul/kadikoy/kahvalti
/istanbul/beyoglu/burger
/ankara/cankaya/pizza
/izmir/alsancak/meze
```

**Amaç:** Long-tail, yüksek dönüşüm oranlı lokal sorgular
**Hedef keyword türü:** `[ilçe]'de [kategori]`, `[ilçe] [kategori] fiyat`

#### Tier 3: İşletme Detay (dinamik)
```
/isletme/[slug]

Örnek:
/isletme/kadikoy-kahvalti-evi
```

**Amaç:** İşletme bazlı sorgular, brand search
**Hedef keyword türü:** `[işletme adı]`, `[işletme adı] menü fiyat`

#### Tier 4: Fiyat Endeksi / Keşif (editoryal)
```
/fiyat-endeksi/[sehir]/[kategori]
/en-uygun/[sehir]
/en-iyi/[sehir]/[kategori]

Örnekler:
/fiyat-endeksi/istanbul/kahvalti
/en-uygun/istanbul
```

**Amaç:** Fiyat şeffaflığı anlatısı, link çekme
**Hedef keyword türü:** `en ucuz [şehir] [kategori]`, `fiyat endeksi`

#### Tier 5: Blog / Editorial
```
/blog/[slug]

Örnekler:
/blog/istanbul-restoran-fiyat-artisi-2026
/blog/qr-menu-nedir-nasil-kullanilir
/blog/kadikoy-kahvalti-rehberi
```

## 3. Sayfa Tipleri ve İçerik Şablonları

### 3.1 Şehir + Kategori Sayfası (`/[sehir]/[kategori]`)

**Meta Title:**
```
[Kategori] — [Şehir] | Güncel Fiyatlar & En İyi Restoranlar | Yeedoy
→ Kahvaltı — İstanbul | Güncel Fiyatlar & En İyi Restoranlar | Yeedoy
```

**Meta Description:**
```
[Şehir]'ın en iyi [kategori] restoranları, güncel menü fiyatları ve 
topluluk yorumları. Fiyat geçmişiyle karşılaştır, doğrulanmış menüleri keşfet.
```

**H1:** `[Şehir]'da [Kategori] — [X] Restoran, Güncel Fiyatlar`

**Zorunlu İçerik Blokları:**
1. BreadcrumbList (Ana Sayfa › [Şehir] › [Kategori])
2. Intro paragraf (100-150 kelime, anahtar kelime yoğunluğu %1-2)
3. Restoran grid (kart başına: isim, fiyat aralığı, güven skoru, açık/kapalı)
4. Fiyat karşılaştırma modülü (opsiyonel; kategori bazlı ortalama vs. seçili restoran)
5. İlçe filtresi (SEO-friendly URL — `/istanbul/kadikoy/kahvalti`)
6. FAQ bölümü (5-8 soru, FAQPage schema ile)
7. İç linkleme: Diğer kategoriler (kebap, burger...) + komşu ilçeler

**İç Linkleme Mantığı:**
- Her kategori sayfası → aynı şehrin diğer kategorileri (yatay)
- Her kategori sayfası → alt ilçe sayfaları (dikey)
- Her işletme kartı → `/isletme/[slug]` (derinlik)

---

### 3.2 İşletme Detay Sayfası (`/isletme/[slug]`)

**Meta Title:**
```
[İşletme Adı] — [İlçe], [Şehir] | Menü, Fiyat & Yorumlar | Yeedoy
→ Kadıköy Kahvaltı Evi — Kadıköy, İstanbul | Menü, Fiyat & Yorumlar | Yeedoy
```

**H1:** `[İşletme Adı]`

**Ek İçerik (mevcut yok, eklenecek):**
- Fiyat geçmişi sparkline (son 6 ay, Yeedoy'a özgü differansiyatör)
- "Bu bölgedeki benzer restoranlar" bloğu (iç linkleme)
- Menü item başlıkları H2/H3 olarak render edilmeli (schema + SEO)
- Açık/kapalı durum — real-time, schema ile (`OpeningHoursSpecification`)

---

### 3.3 QR Menü Sayfası (`/m/[slug]`)

**Canonical:** `/isletme/[slug]` → QR menüyü canonical yapma, asıl sayfaya işaret ettir.

**Yüzey İyileştirmeleri:**
- Tüm menü item görselleri için `alt` text: `[item adı] — [işletme adı]`
- Menü bölümleri (Başlangıçlar, Ana Yemekler) → H2/H3 başlık
- Menü item açıklamaları tam metin (50+ karakter)

---

### 3.4 Blog / Editorial (`/blog/[slug]`)

**Meta Title:** `[Başlık] | Yeedoy Blog`

**Minimum İçerik:**
- 1.500+ kelime
- 3+ dahili bağlantı (ilgili şehir/kategori sayfalarına)
- 1+ dış kaynak (istatistik referansı)
- İlk paragrafta hedef anahtar kelime

**Örnek Konu Planı:**
1. "İstanbul Restoran Fiyat Endeksi 2026 — Kategoriye Göre Analiz" (bağlantı: `/fiyat-endeksi/istanbul/…`)
2. "QR Menü Nedir, Nasıl Kullanılır?" (bağlantı: `/qr/…`)
3. "Kadıköy Kahvaltı Rehberi: En İyi 15 Yer ve Fiyat Karşılaştırması" (bağlantı: `/istanbul/kadikoy/kahvalti`)
4. "Türkiye'de Yemek Fiyatı Artışı — Veriye Dayalı Analiz"

### 4.6 Next.js'de Schema Implementasyonu

```tsx
// uygulamalar/web/app/isletme/[slug]/page.tsx

import { Metadata } from 'next';

export function generateRestaurantSchema(business: Business) {
  return {
    '@context': 'https://schema.org',
    '@type': 'Restaurant',
    name: business.name,
    url: `https://yeedoy.com/isletme/${business.slug}`,
    address: {
      '@type': 'PostalAddress',
      addressLocality: business.district,
      addressRegion: business.city,
      addressCountry: 'TR',
    },
    aggregateRating: business.rating ? {
      '@type': 'AggregateRating',
      ratingValue: business.rating.toString(),
      ratingCount: business.reviewCount,
    } : undefined,
    hasMenu: `https://yeedoy.com/m/${business.slug}`,
  };
}

// page.tsx'de:
export default function IsletmePage({ params }: { params: { slug: string } }) {
  const schema = generateRestaurantSchema(business);
  return (
    <>
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{ __html: JSON.stringify(schema) }}
      />
      {/* sayfa içeriği */}
    </>
  );
}
```

## 5. Sitemap Stratejisi

### 5.1 Sitemap Mimarisi

```
robots.txt
└─ sitemap-index.xml
   ├─ sitemap-static.xml         (ana sayfalar, ~10 URL)
   ├─ sitemap-businesses.xml     (işletmeler, günlük güncelleme)
   ├─ sitemap-categories.xml     (şehir/ilçe/kategori, haftalık)
   ├─ sitemap-menus.xml          (QR menü sayfaları, günlük)
   └─ sitemap-blog.xml           (blog yazıları, ayda 2x)
```

### 5.2 Öncelik Tablosu

| Sayfa Tipi | Priority | ChangeFreq | Güncelleme Tetikleyicisi |
|---|---|---|---|
| Ana Sayfa | 1.0 | weekly | Manuel |
| Keşif / Ana kategori | 0.9 | weekly | İşletme ekleme |
| Şehir + Kategori | 0.8 | monthly | İlk oluşturma |
| İşletme Detay | 0.8 | weekly | Fiyat/menü değişikliği |
| QR Menü | 0.7 | daily | Menü güncelleme |
| Blog | 0.7 | monthly | Yayın |

### 5.3 Next.js App Router Implementasyonu

```typescript
// uygulamalar/web/app/sitemap.ts

import { MetadataRoute } from 'next';
import { createSupabasePublicClient } from '@/src/lib/taban/acik';

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const baseUrl = 'https://yeedoy.com';
  const supabase = createSupabasePublicClient();

  // Statik sayfalar
  const staticPages: MetadataRoute.Sitemap = [
    { url: baseUrl, changeFrequency: 'weekly', priority: 1.0 },
    { url: `${baseUrl}/kesif`, changeFrequency: 'weekly', priority: 0.9 },
    { url: `${baseUrl}/blog`, changeFrequency: 'monthly', priority: 0.7 },
  ];

  // Aktif işletmeler
  const { data: businesses } = await supabase
    .from('businesses')
    .select('slug, updated_at')
    .eq('is_active', true)
    .order('updated_at', { ascending: false })
    .limit(5000);

  const businessPages: MetadataRoute.Sitemap = (businesses ?? []).map(b => ({
    url: `${baseUrl}/isletme/${b.slug}`,
    lastModified: new Date(b.updated_at),
    changeFrequency: 'weekly',
    priority: 0.8,
  }));

  // QR menü sayfaları
  const menuPages: MetadataRoute.Sitemap = (businesses ?? []).map(b => ({
    url: `${baseUrl}/m/${b.slug}`,
    lastModified: new Date(b.updated_at),
    changeFrequency: 'daily',
    priority: 0.7,
  }));

  return [...staticPages, ...businessPages, ...menuPages];
}
```

## 6. Canonical ve Duplicate İçerik Yönetimi

### 6.1 Canonical Kural Tablosu

| URL | Canonical Hedef | Açıklama |
|---|---|---|
| `/m/[slug]` | `/isletme/[slug]` | QR menü, işletme sayfasına işaret eder |
| `/isletme/[slug]` | kendi URL'si | Canonical kaynak |
| `/istanbul/kahvalti?sort=price` | `/istanbul/kahvalti` | Filtreli sayfa, parametresiz canonical |
| `/istanbul/kahvalti?rating=5` | `/istanbul/kahvalti` | Query param → canonical temiz URL |
| `/istanbul/kahvalti/page/2` | `/istanbul/kahvalti` | Pagination, ilk sayfaya canonical |

### 6.2 Next.js Metadata API ile Canonical


### 6.3 hreflang (Tek Dil)

Yeedoy şu an yalnızca Türkçe hizmet vermektedir. İki tag yeterli:

```html

<link rel="alternate" hreflang="x-default" href="https://yeedoy.com/istanbul/kahvalti" />
```

### 6.4 Pagination Stratejisi

Kategori sayfaları için load-more (infinite scroll) tercih edilmeli; `?page=N` URL'si üretilmemeli. Zorunluysa:
- `/istanbul/kahvalti/2` → canonical: `/istanbul/kahvalti`
- Sayfa 2+ `noindex` olabilir veya `rel=next/prev` kullanılabilir.

### 8.2 `generateStaticParams` ile SSG

```typescript
// uygulamalar/web/app/isletme/[slug]/page.tsx

export async function generateStaticParams() {
  const supabase = createSupabasePublicClient();
  const { data } = await supabase
    .from('businesses')
    .select('slug')
    .eq('is_active', true)
    .order('view_count', { ascending: false }) // En çok görüntülenen önce
    .limit(500); // İlk 500 işletme statik

  return (data ?? []).map(b => ({ slug: b.slug }));
}

// Revalidation stratejisi:
```
